# Hayagrive P — Developer Portfolio

Personal portfolio website for Hayagrive P, a Full-Stack + GenAI engineer.

## Stack

- React 19 + Vite
- Tailwind CSS v4
- Framer Motion
- Lucide React
- React Router DOM

## Setup

```bash
npm install
npm run dev      # Dev server at http://localhost:5173
npm run build    # Production build (Vercel-ready)
```

## Updating Project URLs

All project links are in `src/data/projects.js`. Update `liveUrl` and `githubUrl` for each project once deployed.
